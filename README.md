# Personal Portfolio Website

A responsive personal portfolio built with HTML, CSS, and JavaScript for the IT ELEC 4 final project.

## Files
- `index.html` — website content and sections
- `style.css` — layout, colors, and responsive styling
- `script.js` — mobile navigation and current year

## Before submitting
Search the files for `Your Name`, `your.email@example.com`, `yourusername`, `ADD YEAR`, and sample project descriptions. Replace them with your own accurate information. Add your real achievements and at least three projects or activities you have actually completed. Do not claim certificates or skills you do not have.

## Run locally
Open `index.html` in a web browser.

## Publish on GitHub
1. Sign in to GitHub and create a **public** repository named `personal-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root.
3. Commit the files.

## Deploy on Vercel
1. Sign in to Vercel using your GitHub account.
2. Choose **Add New → Project**.
3. Import the `personal-portfolio` repository.
4. For a plain HTML/CSS/JS site, leave the framework preset as **Other** and leave build/output settings blank unless Vercel requests otherwise.
5. Click **Deploy** and open the generated website URL to test it.

## Final checks
- Test the navigation on desktop and mobile.
- Click every navigation link and the email/GitHub links.
- Check that all personal details and project descriptions are correct.
- Take at least three screenshots showing different website sections.
